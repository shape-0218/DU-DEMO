전시 연락 문구 · 시안 v10

정식 오픈(11-27) 뒤 쓰는 문구를 맨 앞에 — 이미 연락한 곳(등록 완료 알림 · 직접 등록 부탁) / 처음 연락. 런칭 전 분류는 기록으로 그대로 둠. 각 분류 안은 보내는 순서대로. 문구는 모두 제안이고, 노란 칸은 보낼 때 채울 곳. v10(11-27): 이미 연락한 곳 4개 추가, 처음 연락 2개를 실제 사이트 링크·경로로, 등록 방법 5줄에 작가 인증·등록 요청·심사·팀원 초대(U-195) — 첫 연락은 로그인·단계 없이 "소개하고 싶다" + 한 문장(U-197), 자세한 건 답장용 등록 방법 안내(U-198: 방법 3줄 + 팀원 초대로 함께 작품·관리, U-199: 학교 웹메일 인증 설명). v8(11-20): ②에 폼 링크 · "전시 자료를 보내주시면…" 문장으로 통일.

런칭 뒤 보내기 전에 (11-27)

  1. 등록 방법 안내(답장용)는 실제 사이트에서 끝까지 따라가 보기 — 이번에 본 것은 홈 맨 아래 '전시 등록하기' → '로그인이 필요해요' 창(카카오로 시작하기 · Google로 시작하기)까지예요(로그인하지 않은 상태). 로그인 뒤 작가 인증(학교 고르기 → 웹메일 주소 → 인증번호), 등록 요청, 심사 '보통 1~2일', 팀원 초대·관리자 지정은 자주 묻는 질문과 프로토에 있는 내용이고, 실제 사이트에서는 못 봤어요. 특히 '보통 1~2일'은 운영팀이 지켜야 하는 약속이라 맞는지 확인.
  2. 학교 이메일 인증이 되는 학교인지 — 인증되는 학교 목록은 개발 쪽에 확인 중이에요. 안 되는 학교면 직접 등록 부탁 대신 자료를 받아 운영팀이 등록.
  3. 끝난 전시는 직접 등록이 안 돼요 — 정책상 지난 기간은 등록할 수 없어요(만든 뒤에 끝난 전시만 요청 가능). 끝난 전시 팀에는 직접 등록 부탁을 보내지 않기.
  4. 등록 완료 알림은 전시가 공개된 걸 확인하고 — 전시 페이지 주소는 https://www.displayu.co.kr/display/번호.
  5. 포스터 장수 한도 — 장당 20MB는 실제 사이트에서 확인됨(11-26). 최대 5장은 프로토 기준이라 실제 사이트에서 확인 필요.
  6. 하루 40개씩 나눠 보내기 — 새 계정이 비슷한 메시지를 몰아 보내면 DM이 막힐 수 있어요(정확한 한도는 공개되지 않음).
  7. 보낸 곳 기록 — 노션 전시 리스트업에 상태·보낸 날.

채울 것

  1. 전시 페이지 링크 — 등록 완료 알림.
  2. 끝난 전시 폼 마감 날짜 — 런칭 전 마감(11월 26일)이 지나서 새로 정하기.

정한 것 (11-19 ~ 11-27)

  1. 오픈 뒤(11-27)엔 진행 중·예정 전시에 디유에서 직접 등록을 부탁 — 피드백도 함께 받기(11-26 사용자).
  2. 오픈 시기 — 첫 연락에 "곧 있을 디유 정식 오픈(11월 말 ~ 12월 초)에 맞춰 등록 후 연락드릴 예정입니다"(11-20). 답장 마감 날짜도 그대로.
  3. 비용 — 들지 않지만 연락 문구에서는 말하지 않음(11-20).
  4. 디유 SNS 소개는 약속하지 않음 — 모르는 계정이 소개까지 해 준다고 하면 반감이 있을 수 있어서.
  5. 보내는 이름 — 사람 이름 대신 디유(displayU) 홍보팀.
  6. 넘겨 드리기 — 미정(11-22: 관리가 어려울 수 있어 검토 중). 연락 문구에서는 말하지 않음.
  7. 자료 — 구글폼 하나(11-20): 포스터만이면 압축 파일 업로드, 작품·전시 콘텐츠까지면 구글 드라이브 링크(작품마다 폴더 '작품명_작가명' + 사진·소개 글). 작가 동의 확인·공유 설정·파일 이름 같은 안내는 DM이 아니라 폼에서. 작품 분야·제작 연도는 받지 않고 운영팀이 학과·전시 연도로 채움. 받는 대로 바로 올리고 알림.
  8. 오픈 전 보여 줄 링크 = 데모(프로토), 오픈 뒤 = 전시 페이지 링크. 첫 연락에도 데모 링크를 한 줄 설명과 함께 넣음(11-20).
  9. 동의 — 보내 주신 것 = 올려도 되는 것으로 가볍게, "수정하거나 내리고 싶은 부분이 있으면 말씀해 주세요".
  10. 끝난 전시에도 연락(11-20) — 목적은 기록·아카이빙. 끝난 전시는 지도에 나오지 않아(프로토 정책) 지도 이야기는 빼고 "전시를 못 본 분들도 언제든 감상"을 앞세움, 작품 사진·전시장 사진·브로셔를 함께 요청.
  11. 끝난 뒤에 올리는 전시 = 운영팀이 DB에 승인된 전시로 직접 넣음(11-20) — 심사 단계가 없고, 상태는 날짜로 정해져 다른 끝난 전시처럼 '종료'로 보임.
  12. 말투 — 기존 마케팅 양식처럼 "~입니다 · 연락드렸습니다 · 감사합니다", 받는 곳은 "〈학교 학과〉 담당자님!", 끝은 "디유(displayU) 홍보팀 드림".

이렇게 쓴 이유

  1. 말투는 기존 양식 그대로 — 업무 연락에서 흔히 쓰는 말투라 사람이 쓴 것처럼 읽혀요. 반대로 "~해서요"로 끝나는 짧은 말, 장점을 나란히 늘어놓는 문장, 감성적인 칭찬은 AI 티가 나서 뺐어요.
  2. 누구인지와 용건을 처음 두세 줄에 — 처음 연락하는 메일·DM은 소속과 목적을 도입부에서 바로 밝히는 게 기본이에요.
  3. 할 일(전시 자료) · 기한을 처음부터 — 조건이 모호하면 되묻게 돼서 답이 늦어져요.
  4. 이모지 소제목 · 굵은 글씨 없이 — DM에서는 광고처럼 보여요.
  5. 데모 링크는 끝 쪽에, 무엇인지 한 줄 뒤에 — 요청함 미리보기는 인사·소개로 시작하고, 받는 쪽은 링크를 누르기 전에 무엇인지 알 수 있어요. 데모에는 처음 보는 전시가 나오니 "AI 목업 전시/작품"이라고 밝혀 둠(11-20 사용자 문구).
