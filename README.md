# 디유(displayU) 웹 프로토타입

디유 서비스의 **반응형 웹 프로토타입**입니다. Figma 디자인을 바탕으로 만든 정적 HTML이며, 서버·로그인·DB 없이 화면의 모양과 동작을 확인하기 위한 **데모**입니다. 개발 참고용으로 공유합니다.

- 실제 정책(권한, 상한, 흐름)은 Notion 정책 문서와 기능명세가 기준입니다. 이 코드는 시각·동작 참고용이에요.
- 전시·작가·학교 이름과 이미지는 모두 **가상 데이터**입니다.
- 이 저장소의 `main`에 반영되면 Vercel이 자동으로 다시 배포합니다.

## 바로 보기

빌드 과정이 없습니다. 이 폴더를 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000  → home.html 로 이동
```

폰 폭은 402px 기준, 태블릿 768px, 노트북 900px 이상에서 레이아웃이 넓어집니다. 크롬 개발자도구의 기기 모드로 확인하세요.

## 공통 코드 (`assets/`)

| 파일 | 역할 |
| --- | --- |
| `flow.css`, `flow.js` | 토큰·모달·바텀시트·토스트·진행 단계, 전시 목록 데이터(`du.exh`) |
| `work.css`, `exdata.js` | 전시 작업·팀원 관리 스타일, 전시별 작품·섹션·팀원 데모 데이터 |
| `media.js`, `blobdb.js` | 사진·영상 올리기(길이·용량 검사, 썸네일), 큰 파일 보관(IndexedDB) |
| `save.js` | 전시·작품·작가 저장 버튼(보관함) |
| `auth.js` | 로그인이 필요한 동작에서 로그인 안내(폰 바텀시트 / 웹 모달) |

## 데모 상태 바꾸기 (주소 뒤에 붙이기)

| 파라미터 | 효과 |
| --- | --- |
| `?reset=1` | 저장된 데모 데이터 초기화 |
| `?login=0` / `?login=1` | 비로그인 / 로그인 (비로그인이면 저장·좋아요·댓글·마이 등에서 로그인 안내) |
| `?s=prep\|review\|reject\|live\|empty` | `hub.html` 전시 상태별 화면 (저장 안 됨) |
| `?state=before\|after` | `my.html` 작가 인증 전/후 |
| `?tab=` | 상세·탐색·마이의 탭 |

## 데이터 저장 방식 (데모 전용)

서버가 없어서 값은 브라우저에만 저장합니다. 실제 서비스에서는 API로 바뀌는 부분입니다.

- `localStorage`: `du.exh`(전시 목록), `du.d.<전시id>`(작품·섹션·팀원), `du.saved`(보관함), `du.auth`(로그인 상태), `du.view`(작품 감상 방식), `du.works`, `du.cert`(작가 인증 정보)
- `IndexedDB` `du.media`: 등록한 포스터 원본(영상 포함)

## 디자인 토큰

색·반경·여백은 CSS 변수로 Figma 변수와 같은 이름 규칙을 씁니다(`--text-primary`, `--bg-secondary`, `--border-primary`, `--r12` …, `assets/flow.css`의 `:root`). 글꼴은 Pretendard(CDN)입니다.

## 개발 참고

- 영상은 목록·카드에서는 썸네일, 홈은 대표 포스터만 재생, 상세에서 재생합니다. 한도(포스터 30초·200MB, 작품 3분·500MB)는 협의 중인 값입니다.
- 이미지 형식·용량 검증, 영상 변환, 권한 검사는 데모에서 흉내만 냅니다. 서버 검증이 필요합니다.
- 문구 중 임시 표기가 있는 것은 정책 문서의 ❓/⏳ 항목을 따릅니다.
